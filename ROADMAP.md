# ResearchHub Roadmap

## Sprint 0 - Contract and Architecture

Goal:
Prepare the repository for safe agentic development.

Deliverables:

```text
AGENTS.md
ARCHITECTURE.md
ROADMAP.md
TASKS.md
SECURITY.md
DATABASE_PLAN.md
UI_UX_GUIDE.md
REPORT_TEMPLATE.md
```

Acceptance:

- All contract files exist.
- Architecture is clear.
- Agent rules are clear.
- Security rules are clear.
- Task report format is clear.

## Sprint 1 - Foundation

Goal:
Build clean app foundation.

Deliverables:

- Laravel project
- PostgreSQL config
- Filament panel
- Email-password login
- Google Login plan or placeholder
- Basic dashboard shell
- Roles and permissions plan
- Activity log baseline

## Sprint 2 - Research Workspace

Goal:
Allow users to manage multiple research projects.

Deliverables:

- Research project CRUD
- Project members
- Project-level roles
- Project dashboard
- Project policies
- Project activity log

## Sprint 3 - Google Drive Integration

Goal:
Allow each user to connect their own Google Drive.

Deliverables:

- Google OAuth connection
- Encrypted token storage
- Drive connection status
- Auto-create ResearchHub folder
- Auto-create project folders
- Drive error handling
- Disconnect/reconnect flow

## Sprint 4 - Document Vault

Goal:
Manage all research documents.

Deliverables:

- Document categories
- Document metadata
- Document upload to Drive
- Document versions
- Document status workflow
- Document comments
- Document approval status
- Audit log

Goal:

Deliverables:
